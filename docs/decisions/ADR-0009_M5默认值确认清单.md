# ADR-0009 M5 Spec 默认值确认清单

> 状态：已决（A/B/C 类全部确认）
> 日期：2026-08-23
> 确认人：用户（"全部照单"）
> 上游依据：ADR-0008、M5 Spec v0.1 审查清单

本文件登记 M5 Spec v0.1 中「章程未写、ADR 未覆盖、起草时由 AI 补默认值」的项，经用户逐条确认后固化为正式依据。

---

## A 类 · 门槛

| 编号 | 项 | 确认值 |
|---|---|---|
| A1 | Schema 检测单次耗时 | ≤5s |
| A2 | 数据质量检查频率 | 每日凌晨（cron） |

## B 类 · 结构/实现默认

| 编号 | 项 | 确认值 |
|---|---|---|
| B1 | schema_changes.change_type | table_added/field_added/field_modified/index_changed |
| B2 | data_quality_alerts.alert_type | null_rate/enum_drift/volume_spike |
| B3 | 血缘通知 | 复用 data_quality_alerts 表（alert_type=metric_lineage_notice） |

## C 类 · 非目标裁剪

| 编号 | 项 | 确认值 |
|---|---|---|
| C1 | Schema 指纹 Caffeine L1 加速 | M5 不做，先 MySQL |
| C2 | 血缘消息推送 | 不做，仅落库 |
| C3 | 数据质量自动修复 | 不做，只告警 |
