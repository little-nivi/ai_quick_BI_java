# ADR-0003 M2 Spec 默认值确认清单

> 状态：已决（A/B/C 类全部确认）
> 日期：2026-08-22
> 确认人：用户（"全部照单"）
> 上游依据：ADR-0001（D-11~D-15）、M2 Spec v0.1 审查清单

本文件登记 M2 Spec v0.1 中「章程未写、ADR-0001 未覆盖、起草时由 AI 补默认值」的项，经用户逐条确认后固化为正式依据。

---

## A 类 · 门槛与编号

| 编号 | 项 | 确认值 |
|---|---|---|
| A1 | 登录错误码 | 新增 `40101`（鉴权失败） |
| A2 | 指标命中准确率验收门槛 | ≥80% |
| A3 | token_used / confidence 字段 | M2 恒空（NULL）占位 |

## B 类 · 表结构默认

| 编号 | 项 | 确认值 |
|---|---|---|
| B1 | users 业务字段可空性 | age/gender/city/register_date/vip_level 可空；role/data_scope/password_hash/is_system_account 有默认/非空 |
| B2 | metric_lineage 表 | lineage_id / metric_id / downstream_report 三字段 |
| B3 | business_glossary 表 | glossary_id / term / mapping 三字段 |

## C 类 · 非目标裁剪

| 编号 | 项 | 确认值 |
|---|---|---|
| C1 | Schema BM25 召回 | M2 不做，继续固定 schema 注入 |
| C2 | 指标审批 UI | M2 只做后端 status 字段 + admin 审批接口，不做完整 UI |
