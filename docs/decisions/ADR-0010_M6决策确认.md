# ADR-0010 M6 决策确认

> 状态：已决（D-31~D-33 全部确认）
> 日期：2026-08-23
> 确认人：用户（"全部照单"）
> 上游依据：章程 §系统架构、§技术栈、M6 里程碑

---

## D-31 前端工程位置与构建（方案 A）

- **决策**：前端放独立目录 `frontend/`，Vue3 + Vite + TypeScript 工程，独立 `npm` 构建；部署时 Nginx 转发前端静态资源到后端 API。
- **理由**：与 Java 工程解耦，符合章程「Nginx 前端静态资源 + API 转发」架构。

## D-32 LangFuse 观测推迟

- **决策**：M6 先做前端，LangFuse 观测作为可选后续（当前无 LangFuse 账号/key，做了无法验证）。
- **理由**：章程「LangFuse 不可用 → 降级为不记录 Trace」，dev 本就不强制。

## D-33 前端页面范围（完整版 C）

- **决策**：4 个页面/模块：
  1. 登录页（用户名/密码 → token）；
  2. 问数主页（输入框 + 图表渲染 ECharts + 溯源面板 + 反馈按钮 + 角色标识）；
  3. 历史记录（会话历史列表）；
  4. 指标管理（配合 M5 审批流：创建/审批/废弃）。

---

## 附：M6 工作方式约定

前端为跨语言工程（Vue3/TS），AI 无法像 Java 那样在本机编译验证，工作方式调整为：
- AI 生成前端代码 → 用户本地 `npm install && npm run build` 验证 → 反馈报错 → AI 修复。
