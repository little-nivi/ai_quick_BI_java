# ADR-0007 M4 Spec 默认值确认清单

> 状态：已决（A/B/C 类全部确认）
> 日期：2026-08-22
> 确认人：用户（"全部照单"）
> 上游依据：ADR-0006、M4 Spec v0.1 审查清单

本文件登记 M4 Spec v0.1 中「章程未写、ADR 未覆盖、起草时由 AI 补默认值」的项，经用户逐条确认后固化为正式依据。

---

## A 类 · 门槛

| 编号 | 项 | 确认值 |
|---|---|---|
| A1 | 语义缓存命中率验收 | ≥30% |
| A2 | 缓存命中响应延迟 | ≤500ms |

## B 类 · 结构/实现默认

| 编号 | 项 | 确认值 |
|---|---|---|
| B1 | session_records 表结构 | record_id / user_id / question / generated_sql / cache_hit / created_at |
| B2 | 空结果缓存 TTL | 5 分钟 |
| B3 | 权限缓存 TTL | 1h |
| B4 | LIMIT 注入值 | 1000 |
| B5 | 降级兜底话术 | "系统繁忙，请稍后重试"（复用 5001） |

## C 类 · 非目标裁剪

| 编号 | 项 | 确认值 |
|---|---|---|
| C1 | Schema 指纹缓存 | M4 不做，留 M5 |
| C2 | 查询缓存 / 会话缓存 | M4 不做 |
| C3 | Redis 实现 | 仅接口预留，不实现 |
| C4 | 多轮上下文记忆 | M4 不做 |
