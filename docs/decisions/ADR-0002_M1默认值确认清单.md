# ADR-0002 M1 Spec 默认值确认清单

> 状态：已决（A~E 类全部确认）
> 日期：2026-08-18
> 确认人：用户（"全部照单"）
> 上游依据：ADR-0001、M1 Spec v0.1 审查清单

本文件登记 M1 Spec v0.1 中「章程未写、ADR-0001 未覆盖、起草时由 AI 补默认值」的项，经用户逐条确认后固化为正式依据。

---

## A 类 · 门槛与编号

| 编号 | 项 | 确认值 |
|---|---|---|
| A1 | 扩展错误码 | `4290`（并发超限）、`5003`（上游格式异常） |
| A2 | M1 验收门槛 | SQL 语法正确率 ≥90%（≥18/20），非端到端 80% |
| A3 | 上游格式异常重试 | 重试 1 次 |

## B 类 · 接口契约数值

| 编号 | 项 | 确认值 |
|---|---|---|
| B1 | 接口路径 | `POST /api/v1/query` |
| B2 | question 长度 | 1–500 字符 |
| B3 | M1 鉴权 | 无 Authorization 头（M2 引入） |
| B4 | 返回结构字段 | `columns / rows / row_count / latency_ms` |
| B5 | 并发超限阈值 | 单实例并发 >10 |
| B6 | 固定话术 | 系统繁忙 / 服务暂时不可用 / 查询超时 / 请求过于频繁 / 系统内部错误 |

## C 类 · 技术选型与实现细节

| 编号 | 项 | 确认值 |
|---|---|---|
| C1 | 语法预解析库 | JSqlParser |
| C2 | Prompt 结构 | 四段：系统指令 + orders schema + few-shot + question |
| C3 | qwen 输出 JSON | `{ "sql", "explanation" }` |
| C4 | few-shot | ≥3 条，覆盖聚合 / 分组 / 时间过滤 |
| C5 | 高危拦截正则 | `\b(DROP\|DELETE\|UPDATE\|ALTER\|TRUNCATE\|INSERT\|CREATE)\b` 或不以 SELECT 开头 |
| C6 | Prompt 注入正则 | `忽略以上指令\|忽略上述\|ignore (all\|above\|previous)\|system 覆盖\|扮演` |

## D 类 · orders 表数据模型

| 编号 | 项 | 确认值 |
|---|---|---|
| D1 | 字段类型 | `amount/price DECIMAL(10,2)`、`order_id BIGINT UNSIGNED AUTO_INCREMENT` |
| D2 | status 默认值 | `completed` |
| D3 | 索引 | `idx_order_date / idx_user_id / idx_region` |
| D4 | Flyway 引入时机 | M1 即引入，脚本 `V1__init_orders.sql` |

## E 类 · 非目标裁剪边界

| 编号 | 项 | 确认值 |
|---|---|---|
| E1 | M1 样例数据 | ≤1 万条（非 150 万） |
| E2 | M1 不做 | RBAC / 缓存 / 意图识别 / 置信度 / 前端 / 审计落库 / users·products 表 |
