# ADR-0005 M3 Spec 默认值确认清单

> 状态：已决（A/B/C 类全部确认）
> 日期：2026-08-22
> 确认人：用户（"全部照单"）
> 上游依据：ADR-0004、M3 Spec v0.1 审查清单

本文件登记 M3 Spec v0.1 中「章程未写、ADR 未覆盖、起草时由 AI 补默认值」的项，经用户逐条确认后固化为正式依据。

---

## A 类 · 门槛

| 编号 | 项 | 确认值 |
|---|---|---|
| A1 | 反问澄清准确率验收 | ≥70% |
| A2 | 自我修正成功率验收 | ≥60% |
| A3 | 中置信处理 | 标"中置信" + 直接执行（ADR D-05 落地，不额外调 LLM） |

## B 类 · 结构/实现默认

| 编号 | 项 | 确认值 |
|---|---|---|
| B1 | LLM 输出结构 | `{ sql, explanation, is_query, confidence }` |
| B2 | trace 溯源结构 | tables / fields / metric / confidence / confidence_level |
| B3 | 自我修正触发错误类型 | 仅语法/字段类；超时 5002 不修正 |
| B4 | 反馈轮询频率 | 5 分钟（M3 仅打日志） |

## C 类 · 非目标裁剪

| 编号 | 项 | 确认值 |
|---|---|---|
| C1 | session 持久化 | M3 不做，反问无状态 |
| C2 | 前端 | M3 不做，仅后端接口 |
