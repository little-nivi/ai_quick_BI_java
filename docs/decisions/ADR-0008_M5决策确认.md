# ADR-0008 M5 决策与默认值确认

> 状态：已决（D-26~D-30 + P1 全部确认）
> 日期：2026-08-23
> 确认人：用户（"全部照单"）
> 上游依据：章程 §数据治理、§指标口径管理、ADR-0001（D-08 审批角色）

---

## D-26 Schema 指纹存储位置

- **决策**：Schema 指纹存 MySQL 表 `schema_fingerprint`（table_name + MD5 指纹 + detected_at）。
- **理由**：M4 已把 Schema 指纹缓存推迟到 M5；M5 先做 MySQL 持久化，Caffeine L1 加速（maximumSize=1）可选。

## D-27 Schema 变更检测频率

- **决策**：`@Scheduled` cron 表达式配置化，默认每小时（`0 0 * * * *`），可用配置覆盖（测试时改短间隔）。

## D-28 数据质量监控规则量化

- **决策**：关键字段 = `orders.amount` / `orders.order_date` / `orders.region`；三条规则：
  1. 空值率 > 10% → 告警；
  2. 枚举值分布突变（某品类订单量突然为 0）→ 告警；
  3. 日数据量波动 > 50%（对比前 7 天均值）→ 告警。

## D-29 指标口径审批流接口

- **决策**：3 个接口，均 admin 权限（ADR D-08）：
  - `POST /api/v1/metrics` 创建指标（status=draft）；
  - `POST /api/v1/metrics/{id}/approve` 审批（draft→published）；
  - `POST /api/v1/metrics/{id}/deprecate` 废弃（→deprecated）。

## D-30 指标血缘通知

- **决策**：血缘变更时落库记录（写入告警/变更通知表），不做消息推送（邮件/IM）；前端展示留 M6。
