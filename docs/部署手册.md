# NL2SQL 上云部署手册（阿里云 ECS）

> 目标环境：阿里云 ECS（99元/年，2核2G + 40G ESSD + 3M带宽），Ubuntu 22.04 LTS
> 配套文件见 `deploy/` 目录

---

## 0. 部署拓扑

```
ECS (2核2G)
 ├── JDK 17 + Spring Boot 应用（JVM -Xmx960m）
 ├── Nginx（反向代理 80 → 8080）
 ├── Docker MySQL 8.0（--memory=512m）
 └── Caffeine 本地缓存（替代 Redis）

外部服务（不占 ECS）
 ├── 通义千问 API（DashScope，按量计费）
 └── LangFuse Cloud（jp.cloud.langfuse.com，免费版）
```

---

## 1. 环境变量清单

部署前准备好，写入 `/etc/default/nl2sql-app`（systemd 用）或 `.env`（docker 用）：

```bash
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=nl2sql
DB_USERNAME=root
DB_PASSWORD=<你的MySQL密码>

DASHSCOPE_API_KEY=<你的通义千问key>
DASHSCOPE_MODEL=qwen-turbo

JWT_SECRET=<随机32字节以上字符串>

LANGFUSE_PUBLIC_KEY=pk-lf-...
LANGFUSE_SECRET_KEY=sk-lf-...
LANGFUSE_BASE_URL=https://jp.cloud.langfuse.com
```

> **禁止**把这些写进代码或提交 git。`.gitignore` 已排除 `.env`。

## 2. 服务器初始化

```bash
# 2.1 基础依赖
sudo apt update && sudo apt install -y nginx openjdk-17-jre-headless docker.io

# 2.2 开启 swap（2G 内存必须，章程 §6.2）
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# 2.3 确认 swap 生效
swapon --show
```

## 3. 数据库（Docker MySQL）

```bash
# 3.1 启动 MySQL 容器
sudo docker run -d \
  --name mysql \
  --memory=512m \
  --restart=always \
  -p 127.0.0.1:3306:3306 \
  -e MYSQL_ROOT_PASSWORD=<你的密码> \
  -e MYSQL_DATABASE=nl2sql \
  -v /data/mysql:/var/lib/mysql \
  mysql:8.0
```

> **Flyway 迁移 OOM 注意**（章程 §5.1）：执行大迁移时临时扩容 `--memory=768m`，迁移完调回 512m：
> ```bash
> sudo docker update --memory=768m mysql   # 迁移前
> sudo docker update --memory=512m mysql   # 迁移后
> ```

## 4. 应用部署

### 4.1 构建并上传 jar

```bash
# 本地构建（或用 Dockerfile 多阶段构建）
mvn package -DskipTests
scp target/nl2sql-app-*.jar root@<ECS公网IP>:/opt/nl2sql/nl2sql-app.jar
```

### 4.2 配置环境变量文件

```bash
sudo mkdir -p /opt/nl2sql
sudo tee /etc/default/nl2sql-app > /dev/null <<'EOF'
DB_HOST=127.0.0.1
DB_PASSWORD=<你的密码>
DASHSCOPE_API_KEY=<你的key>
JWT_SECRET=<随机串>
LANGFUSE_PUBLIC_KEY=pk-lf-...
LANGFUSE_SECRET_KEY=sk-lf-...
LANGFUSE_BASE_URL=https://jp.cloud.langfuse.com
EOF
```

### 4.3 安装 systemd 服务

```bash
# 复制 deploy/nl2sql-app.service
sudo cp nl2sql-app.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable nl2sql-app
sudo systemctl start nl2sql-app
sudo systemctl status nl2sql-app
```

---

## 5. Nginx 反向代理

```bash
# 复制 deploy/nginx.conf
sudo cp nginx.conf /etc/nginx/sites-available/nl2sql.conf
sudo ln -s /etc/nginx/sites-available/nl2sql.conf /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

---

## 6. 日志轮转

```bash
# 复制 deploy/logrotate.conf
sudo cp logrotate.conf /etc/logrotate.d/nl2sql-app
```

## 附：面试话术要点（章程 §12）

1. **资源调优**：2G 内存下 `-Xmx960m` + `MaxMetaspaceSize=320m`（应对 Spring AI 非堆开销）+ swap + Caffeine 替代 Redis；
2. **平滑迁移**：RDS 免费试用 → Docker 自建，`mysqldump` 导出导入 + 配置热切换零停机；
3. **生产级架构**：Nginx 反代 + LangFuse 链路追踪 + HikariCP 调优 + logrotate + systemd 自动重启；
4. **成本意识**：云厂商免费资源 + 内嵌缓存，月成本控制在 100 元左右。
