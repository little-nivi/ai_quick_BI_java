## 使用说明

- 每条用例格式：`问题 | 类别 | 预期 SQL 要点 | 判定标准`
- **判定标准**三档：
  - `code` —— 期望返回的错误码（如 4003 安全拦截、4001 非问数）；
  - `sql` —— 期望 SQL 包含的关键词（如 `SUM(amount)`、`GROUP BY region`）；
  - `result` —— 期望结果特征（如 rowCount ≥ 1、结果为数值）。
- **JOIN 类（20 条）** 依赖 `users` 表业务用户数据，当前未造数，标注 ⚠️ 待启用。
