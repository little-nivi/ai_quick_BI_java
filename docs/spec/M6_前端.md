## 0. 非目标（不做）清单

M6 新增「Vue3 前端」。以下明确不做：

- 不做 LangFuse 观测（ADR D-32 推迟）
- 不做成本/延迟监控前端面板（LangFuse 推迟后无数据源）
- 不做 SSR / 服务端渲染（纯 SPA）
- 不做移动端适配（桌面优先）
- 不做多语言 i18n

## 1. 业务目标 & 非功能需求（§2.1）

### 系统能力（M6 增量）

- 登录页：用户名/密码登录，存 token；
- 问数主页：输入自然语言 → 展示 SQL 结果（表格 + ECharts 图表）→ 溯源面板 → 反馈按钮 → 角色标识；
- 历史记录：查看历史会话；
- 指标管理：创建/审批/废弃指标（对接 M5 审批流）。

### 非功能需求（量化）

| 编号 | NFR | 值 | 测量方式 |
|---|---|---|---|
| NFR-17 | 首屏加载 | ≤ 3s | 本地 dev 冷启动至可交互 |
| NFR-18 | 前端构建产物 | ≤ 500KB（gzip 后） | 构建输出大小 |
| NFR-19 | API 请求超时 | 60s | axios 默认超时 |

### 安全红线（量化拦截触发条件）

| 编号 | 红线 | 拦截触发条件 | 拦截动作 |
|---|---|---|---|
| SR-10 | token 失效 | 后端返回 401 | 清除本地 token，跳转登录页 |

> SR-1~SR-9 在后端，前端仅承接后端错误码。

## 2. 系统架构 & 模块划分（§2.2）

### 模块与职责

| 模块 | 职责 | 依赖 |
|---|---|---|
| LoginView | 登录页，存 token 到 localStorage | Auth API |
| QueryView | 问数主页（输入+结果+图表+溯源+反馈） | Query/Feedback API |
| HistoryView | 历史记录列表 | Session API |
| MetricView | 指标管理 | Metric API |
| api/ | axios 封装（baseURL + token 拦截器） | 后端 |

依赖方向（无环）：各 View → `api/` → 后端 REST。

### 技术栈

- Vue3 + TypeScript + Vite；
- ECharts（图表）；
- vue-router（路由）；
- axios（HTTP）；
- pinia（可选，状态管理）。

---

## 3. 数据模型（§2.3）

前端无独立持久化数据模型；仅 localStorage 存 `token`、`role`、`data_scope`（会话级）。

---

## 4. 接口契约（§2.4）

> 前端对接后端已有接口，本 Spec 只定义前端侧对接口的调用约定，不改后端契约。

| 前端动作 | 后端接口 | 说明 |
|---|---|---|
| 登录 | `POST /api/v1/auth/login` | 返回 token/role/data_scope，存 localStorage |
| 问数 | `POST /api/v1/query` | 携带 token；返回含 sql/rows/columns/trace/cache_hit |
| 反馈 | `POST /api/v1/feedback` | 正/负反馈 |
| 创建指标 | `POST /api/v1/metrics` | admin 权限 |
| 审批指标 | `POST /api/v1/metrics/{id}/approve` | admin 权限 |
| 废弃指标 | `POST /api/v1/metrics/{id}/deprecate` | admin 权限 |

> 历史记录接口（`GET /api/v1/sessions`）后端 M6 需新增——见 §5 REQ-526。

## 5. 核心业务逻辑（§2.5）

### REQ-526 历史记录查询接口（后端新增）

- 新增 `GET /api/v1/sessions`，返回当前用户最近的 `session_records` 列表（按 created_at 倒序，限 50 条）；
- 响应：`{ code: 2000, data: [ { question, generated_sql, cache_hit, created_at } ] }`。

### REQ-527 前端图表渲染

- 问数结果若 `columns` 含数值列 + 维度列（如 region 分组），自动用 ECharts 渲染柱状图；
- 单值聚合（如 SUM）显示为指标卡 + 数字；
- 无维度则仅表格。

### REQ-528 前端溯源面板

- 结果下方提供"查询依据"面板，展示 `trace`（表/字段/指标/置信度）；
- 可折叠展开。

### REQ-529 前端反馈按钮

- 每个结果下方提供"有用/无用"按钮；
- "无用"弹出输入框，可填正确问法/SQL，调 `/api/v1/feedback`。

### REQ-530 前端角色标识

- 登录后根据 `role` 显示角色徽章；operator 显示其 `data_scope` 区域提示。

## 6. 边界 Case、兜底策略、验收标准（§2.6）

### 验收 Case（Given/When/Then）

```
TC-526-01（验证 REQ-526 历史记录）
Given: 用户已登录且有历史会话
When:  调用 GET /api/v1/sessions
Then:  返回最近 session_records 列表（≤50 条）

TC-527-01（验证 REQ-527 图表渲染）
Given: 问数返回 region 分组结果
When:  前端渲染
Then:  显示 ECharts 柱状图

TC-528-01（验证 REQ-528 溯源面板）
Given: 问数成功返回 trace
When:  点击"查询依据"
Then:  展开显示表/字段/指标/置信度

TC-530-01（验证 REQ-530 角色标识）
Given: operator 登录
When:  进入问数主页
Then:  显示 operator 徽章 + data_scope 区域提示
```

### 验收成功判定（M6 完成标准）

- 上表 4 条 TC 全部通过；
- 前端可登录 → 问数 → 看图表 → 看溯源 → 提交反馈完整走通；
- `npm run build` 成功无报错。
